# 观自在 · Guān Zì Zài

> 一念通佛道，指尖悟修行。

「观自在」是一个**纯静态、零依赖**的佛道双修虚拟修行网页。山门选门而入，佛门礼佛诵经、道门朝礼存神，于方寸屏幕间安顿身心。所有音效由 Web Audio 实时合成，所有图像由内联 SVG 绘制，**不依赖任何外部资源、不发送任何网络请求**。

---

## ✨ 特性

- **双传统切换**：佛门（金褐庄严）/ 道门（玉青水墨），视觉、仪轨、文案、法器音各异。
- **五大仪轨交互**
  - **礼拜 / 朝礼**：长按拜垫蓄力成一拜，三拜礼成计一轮；参拜者俯身、引磬（佛）/ 道钟（道）相应，三清位牌随拜高亮。
  - **上香 / 焚香**：三炷香依次点燃，青烟由 canvas 实时升腾；可敬献供品与心愿，心愿上浮成烟。
  - **木鱼 / 云磬**：敲击计数、涟漪与浮字、自动敲击、快慢自适应；佛 108 声、道 81 声圆满。
  - **佛珠 / 道珠**：108 / 81 颗念珠 SVG 渲染，点击或沿珠圈拖动拨珠，过母珠记一串圆满。
  - **今日功课 / 日课**：四门功课卡片、每日经典语录、回向文、清课重置。
- **沉浸音景**：法器音（木鱼、引磬、云磬、道钟、拨珠、点香、圆满）+ 可选「禅境」底噪（低频 + 呼吸式 LFO + 远处钟磬）。首次点击页面后解锁（浏览器音频策略）。
- **本地持久化**：修行记录存于浏览器 `localStorage`（key `guanzizai.v1`），按日重置当日进度，累计功德跨日保留。
- **响应式**：桌面端左侧仪轨栏，移动端底部标签栏；支持 `prefers-reduced-motion`。
- **纯静态可部署**：无需构建步骤，Hash 路由保证刷新与分享直链可用。

## 🚀 本地运行

任意静态服务器即可，无需安装任何依赖：

```bash
# Python
cd avalokita
python3 -m http.server 8099
# 浏览器打开 http://127.0.0.1:8099

# 或 Node
npx serve avalokita
```

> 直接双击 `index.html` 以 `file://` 方式打开也能运行，但个别浏览器对 `localStorage` 在 `file://` 下的行为有限制，建议用本地服务器。

## ☁️ 部署到 Vercel

项目已自带 `vercel.json`，按纯静态站服务：

1. 将 `avalokita` 文件夹推送到任意 Git 仓库（GitHub / GitLab）。
2. 在 Vercel 导入该仓库：
   - **Framework Preset** 选 **Other**（无构建）
   - **Root Directory** 为仓库根（即 `avalokita/`）
   - **Build Command / Install Command** 留空
3. 点击 **Deploy**。

部署后 `index.html` 位于站点根 `/`，Hash 路由（如 `#/buddha`、`#/tao/incense`）支持刷新保持与分享直链。

其他静态托管（Cloudflare Pages、GitHub Pages、Netlify、Nginx）同样适用，只需把整个文件夹作为静态根目录。

## 🛠 技术栈

- 原生 HTML + CSS + JavaScript（ES5 风格，无框架、无打包）。
- Web Audio API（音效实时合成，无音频文件）。
- Canvas 2D（青烟粒子）+ 内联 SVG（法器、念珠、太极八卦、莲花等）。
- Hash 路由（`hashchange`）+ `localStorage` 持久化。
