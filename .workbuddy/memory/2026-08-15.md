# 2026-08-15 · 观自在 修行网站

完成「观自在」(avalokita) 佛道双修虚拟修行网站的剩余交互模块，站点现已可运行、可部署 Vercel。

## 结构
- `index.html` 山门(门选佛/道) + 殿堂(五仪轨面板)，纯静态、无构建步骤。
- `styles/` base.css(通用) + buddha.css(金褐) + tao.css(玉青水墨)，靠 `body[data-tradition]` 切换。
- `scripts/` store.js(localStorage, 按日重置 cur) / audio.js(Web Audio 实时合成法器音，无音频文件) / config.js(两宗 TRADITIONS 文案与参数) / app.js(GZ 单例:路由/公共能力) + mod-bow/incense/knock/beads/course.js。
- `vercel.json` 纯静态部署：`buildCommand:null`, `outputDirectory:"."`, 缓存 scripts/styles。

## 五仪轨
- bow 长按蓄力三拜(引磬/道钟音, 进度环, 三清位牌高亮)
- incense 三炷香点燃 + canvas 青烟 + 供品 + 心愿上浮
- knock 木鱼/云磬 计数 + 自动敲击 + 108/81 圆满
- beads 108/81 念珠 SVG，点击/拖动拨珠
- course 功课卡片 + 每日语录 + 回向/清课
